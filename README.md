# 📊 Customer Churn Prediction Dashboard

An end-to-end Machine Learning project that predicts whether a telecom customer is likely to churn and displays the churn risk through an interactive Streamlit dashboard.

## 🚀 Features

- Customer churn prediction using Machine Learning
- Data preprocessing and categorical encoding
- XGBoost classification model
- Churn probability/risk score
- High, Medium, and Low risk classification
- Interactive Streamlit dashboard
- Model saved using Joblib

## 🛠️ Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Joblib
- Matplotlib
- Seaborn
